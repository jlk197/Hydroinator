# Hydroinator

A Flutter mobile app for taking care of houseplants — reminds you to water them, keeps a photo history of every plant, and lets you "bury" the ones that didn't make it.

## Features

- **Plant list** — each plant has a name, add date, watering interval, and a photo gallery.
- **Watering schedule** — tells you when to water a plant ("today", "tomorrow", "in N days").
- **Local notifications** — daily / weekly / every N days at the chosen time, DST‑safe (wall‑clock time is preserved across summer ↔ winter time changes, time zone `Europe/Warsaw`).
- **Plant cemetery** — wilted plants go to a separate view with their date of death.
- **User account** — sign‑in and data sync via Firebase (Auth + Firestore + Storage for photos).
- **Offline mode** — local Isar database for user settings and `path_provider` for files.
- **Polish UI** — `flutter_localizations` with `Locale('pl')`.

## Tech stack

- **Flutter** (Dart SDK `>=3.3.1 <4.0.0`), Material 3
- **flutter_bloc** + **bloc** + **equatable** — state management
- **get_it** — dependency injection (`lib/services/locator.dart`)
- **isar_community** (+ `isar_flutter_libs`, `isar_community_generator`) — local database
- **firebase_core**, **firebase_auth**, **cloud_firestore** — backend
- **flutter_local_notifications** + **timezone** — DST‑aware notifications
- **image_picker** + **cached_network_image** — plant photos
- **carousel_slider**, **intl**, **http**

## Requirements

- Flutter SDK with Dart `>=3.3.1 <4.0.0`
- Android Studio / Xcode for native builds
- A Firebase project with Authentication, Firestore, and Storage enabled
- Installed CLIs: `flutter`, `dart`, `firebase`, and `flutterfire_cli`

## Getting started

1. Clone the repo and install dependencies:

   ```bash
   flutter pub get
   ```

2. Configure Firebase (generates `lib/firebase_options.dart`):

   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```

3. Generate Isar code for entities:

   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```

4. Run the app:

   ```bash
   flutter run
   ```

## Release builds

- Android APK: `flutter build apk --release`
- Android App Bundle: `flutter build appbundle --release`
- iOS: `flutter build ipa --release` (requires macOS + Xcode)

Launcher icons are generated by `flutter_launcher_icons` from `assets/icon/icon.jpg` — after changing the icon, run:

```bash
dart run flutter_launcher_icons
```

## Permissions

- **Android** — notifications (`POST_NOTIFICATIONS`), gallery/camera access for `image_picker`. Notifications are scheduled in the `Europe/Warsaw` time zone with wall‑clock semantics, so the time picked in the UI (e.g. 17:00) is preserved across summer ↔ winter DST changes.
